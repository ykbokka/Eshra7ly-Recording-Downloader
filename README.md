# Eshra7ly Recording Downloader

A community-made tool for saving recordings from Eshra7ly courses that you are personally authorized to access.

> **Important:** This project is provided for personal, authorized use only. Having access to a course does not necessarily mean you have permission to download, retain, or redistribute its recordings. Check Eshra7ly's current terms and applicable law before using this software.

## Intended use

- Sign in with **your own Eshra7ly account**.
- Download only recordings from courses you have legitimately enrolled in and purchased, and only where downloading is permitted.
- Keep downloaded recordings for your own permitted use.
- Respect the rights of course instructors and other copyright holders.

## Not permitted / not intended

Do not use this project to access courses or recordings you have not purchased or are not otherwise authorized to access. Do not share account credentials, redistribute or sell recordings, or use the software to infringe copyright or bypass access restrictions. Do not use another person's account or session without their explicit authorization.
